# Part 2:

## Project Overview
A website for VeeMoo Bites, a Bloemfontein-based business selling biltong and meat hampers, delivered to customers' doors.

## Website Goals and Objectives
Move order-taking from WhatsApp/Facebook onto a structured online enquiry form, and showcase the hamper range to attract new customers.

## Key Features and Functionality
- Homepage, About, Products, Enquiry, Contact pages
- Product listing for biltong packs and 5 meat hampers, styled as card layouts
- Order enquiry form
- Contact page with delivery area, Waterfront Mall collection point, and embedded map
- Responsive design across desktop, tablet, and mobile

## Sitemap
Home -> About -> Products -> Enquiry -> Contact (all linked via navigation menu)

## Responsive Design Evidence
Screenshots demonstrating the website's responsive layout across screen sizes are available in the `/screenshots` folder:
- `desktop-view.png` - Desktop layout
- `tablet-view.png` - Tablet layout (768px breakpoint)
- `mobile-view.png` - Mobile layout (480px breakpoint)

## Part 1 Details
Basic HTML structure completed for all 5 pages, with header, nav, main, and footer sections. Research and content sourced from client-provided hamper flyers and business information.

## Part 2 Details
- Created an external stylesheet (`css/style.css`) and linked it to all 5 pages.
- Applied a base style (reset, typography using Google Fonts Poppins, black/orange/white colour scheme matching the VeeMoo Bites brand).
- Styled header, navigation, hamper product cards, and footer using Flexbox.
- Implemented a 2-per-row card layout for hamper products with hover states on navigation links.
- Added responsive design with media query breakpoints for tablet (768px) and mobile (480px), including stacked navigation and single-column hamper cards on mobile.
- Tested layout across desktop, tablet, and mobile screen sizes using browser developer tools. Screenshots included in `/screenshots`.
